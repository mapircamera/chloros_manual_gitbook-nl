# Uitvoerbeeldformaten

### TIFF (16-bits)

16-bits (digitaal pixelgetal 0 - 65535) TIFF (.tif) formaatuitvoer.

### TIFF (32-bits, procent %)

32-bits (pixel float 0,0 - 1,0) uitvoer in TIFF (.tif)-formaat. Pixelwaarden vertegenwoordigen reflectiepercentages waarbij 0,0 = 0% en 1,0 = 100%.

### **JPG (8-bits)**

8-bits (digitaal pixelgetal 0 - 255) uitvoer in JPG-formaat (.jpg).

### **PNG (8-bit)**

8-bit (digitaal pixelgetal 0 - 255) PNG (.png) formaatuitvoer. Verliesloze compressie geschikt voor weergave op het web en visualisatie.
